1. TOKEN - Podstawowa Jednostka Tekstu

Definicja: Najmniejsza jednostka tekstu rozumiana przez model AI
Język Przykład Tokenizacji Liczba Tokenów
Angielski "Hello world!" → ["Hello", " world", "!"] 3
Polski "Cześć świecie" → ["Cze", "ść", " świ", "ecie"] 4
Kod "def hello():" → ["def", " hello", "(", ")", ":"] 5

Reguły Tokenizacji

  • 1 token ≈ 4 znaki (angielski)
  • 1 token ≈ 2-3 znaki (polski, chiński)
  • 1 token ≈ ¾ słowa (średnio)
# Python - liczenie tokenów import tiktoken encoder = tiktoken.encoding_for_model("gpt-4") tokens = encoder.encode("Hello world!") print(len(tokens)) # 3

2. VECTOR (Embedding) - Reprezentacja Znaczenia

Definicja: Lista liczb reprezentująca znaczenie tekstu w przestrzeni wielowymiarowej

Przykład

"dog" → [0.2, -0.5, 0.8, 0.1, ..., 0.3] # 1536 liczb "cat" → [0.3, -0.4, 0.7, 0.2, ..., 0.4] # podobny vector! "car" → [-0.8, 0.9, -0.2, 0.5, ..., -0.1] # różny vector

Właściwości Vectorów

Właściwość Opis Przykład
Wymiarowość Liczba elementów w vectorze 1536 (OpenAI), 768 (BERT)
Podobieństwo Bliskie vectory = podobne znaczenie cos(dog, cat) = 0.85
Odległość Dalekie vectory = różne znaczenie cos(dog, car) = 0.12

# Python - tworzenie vectora import openai response = openai.embeddings.create( model="text-embedding-3-small", input="Cześć jak się masz?" ) vector = response.data[0].embedding # [0.123, -0.456, 0.789, ..., 0.234] # 1536 liczb

Obliczanie Podobieństwa

# Cosine Similarity import numpy as np def cosine_similarity(v1, v2): return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2)) similarity = cosine_similarity(vector1, vector2) # 0.0 - 1.0 (1.0 = identyczne)

3. EMBEDDING - Proces Zamiany Tekstu na Vector

Definicja: Proces transformacji tekstu w reprezentację numeryczną (vector)

Przepływ

Tekst → Tokenizacja → Model Embedding → Vector "Hello" → ["Hello"] → Neural Network → [0.2, -0.5, 0.8, ...]

5. RAG (Retrieval Augmented Generation) - Połączenie

RAG = Vectory (search) + Tokeny (generation)
# Krok 1: Przygotowanie (VECTORY) docs = ["Doc 1 text", "Doc 2 text", "Doc 3 text"] doc_vectors = [embed(doc) for doc in docs] vector_db.store(doc_vectors) # Krok 2: User Query (VECTORY) question = "Jak działa AI?" q_vector = embed(question) # Krok 3: Wyszukiwanie (VECTORY) relevant_docs = vector_db.search(q_vector, top_k=3) # Krok 4: Generacja (TOKENY) prompt = f"Context: {relevant_docs}\nQuestion: {question}\nAnswer:" answer = llm.generate(prompt) # używa tokenów!

8. Przykłady Kodu - Quick Reference

OpenAI - Tokeny (Chat)

import openai response = openai.chat.completions.create( model="gpt-4-turbo", messages=[{"role": "user", "content": "Hello!"}] ) print(response.choices[0].message.content) print(f"Tokens: {response.usage.total_tokens}")

OpenAI - Vectory (Embeddings)

response = openai.embeddings.create( model="text-embedding-3-small", input="Your text here" ) vector = response.data[0].embedding # 1536 liczb

AWS Bedrock - Tokeny

import boto3, json bedrock = boto3.client('bedrock-runtime') response = bedrock.invoke_model( modelId='anthropic.claude-v2', body=json.dumps({ "prompt": "Hello!", "max_tokens_to_sample": 100 }) )

AWS Bedrock - Vectory

response = bedrock.invoke_model( modelId='amazon.titan-embed-text-v1', body=json.dumps({"inputText": "Your text"}) ) vector = json.loads(response['body'])['embedding']

Semantic Search

# 1. Embed documents docs = ["Doc 1", "Doc 2", "Doc 3"] doc_vectors = [embed(d) for d in docs] # 2. Embed query query_vector = embed("search query") # 3. Find similar from sklearn.metrics.pairwise import cosine_similarity similarities = cosine_similarity([query_vector], doc_vectors) best_match = docs[similarities.argmax()]
